# ☀️ Solar Energy Production Forecasting

## 📌 Project Overview

A machine learning regression project to predict annual solar photovoltaic (PV) energy production using system characteristics, regional information, developer details, metering method, utility, and installation timing.

The project follows an end-to-end data science workflow covering data exploration, feature engineering, model comparison, hyperparameter tuning, evaluation, feature importance, cross-validation, and production prediction.

---

## 🎯 Objectives

- Analyze solar energy production data
- Identify patterns and relationships between system characteristics and energy output
- Perform data cleaning and feature engineering
- Build and compare multiple regression models
- Tune the Random Forest model using GridSearchCV
- Evaluate model performance using regression metrics
- Identify the most influential features
- Create a reusable prediction function
- Prepare model outputs for Power BI reporting

---

## 📊 Dataset

The original dataset contains:

- **218,115 records**
- **17 columns**

The target variable is:

`Estimated Annual PV Energy Production (kWh)`

After data preparation and filtering, the model-ready dataset contained:

**133,535 records × 11 features**

### Key Features

- Estimated PV System Size (kWdc)
- PV System Size (kWac)
- DC-to-AC ratio
- Energy storage indicator
- Interconnection year
- Interconnection month
- Developer
- Division
- County
- Metering Method
- Utility

## 🛠️ Feature Engineering

Several features were created to improve model performance:

- Interconnection year
- Interconnection month
- DC-to-AC system size ratio
- Energy storage indicator
- Log-transformed target variable

Categorical variables were encoded using `LabelEncoder`.

---

## 🤖 Machine Learning Models

Five regression models were trained and compared:

| Model |
|---|
| Linear Regression |
| Ridge Regression |
| Decision Tree |
| Random Forest |
| Gradient Boosting |

The Random Forest model was subsequently optimized using **GridSearchCV**.

### Random Forest Hyperparameter Tuning

Grid search evaluated:

- `n_estimators`
- `max_depth`
- `min_samples_leaf`
- `max_features`

The search evaluated **72 model configurations across 3-fold cross-validation**.

---

## 📈 Final Model Performance

The tuned Random Forest model achieved the following performance on the held-out test set:

| Metric | Result |
|---|---:|
| R² Score | **0.9998** |
| MAE | **187.37 kWh** |
| RMSE | **3,945.44 kWh** |
| MAPE | **0.08%** |

### Cross-Validation

5-fold cross-validation produced:

- **Mean R²: 0.9996**
- **Standard deviation: 0.0003**

---

## 🔎 Feature Importance

The model identified the following as the most influential features:

1. Estimated PV System Size (kWdc)
2. PV System Size (kWac)
3. DC-to-AC ratio
4. Metering Method
5. Utility

Permutation importance was also used to validate feature influence.

## 🔮 Production Prediction

- Developer

- County
- Metering method
- Utility
- PV system size
- Storage
- Interconnection year
- Interconnection month

**13,484 kWh ≈ 13.5 MWh per year**
