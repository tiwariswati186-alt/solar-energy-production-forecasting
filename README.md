# ☀️ Solar Energy Production Forecasting

## 📌 Project Overview

This project focuses on predicting solar energy production using machine learning regression techniques.

The objective is to analyze solar energy-related features, identify important patterns, build predictive models, and evaluate their performance to determine the most effective approach for forecasting solar energy production.

---

## 🎯 Objectives

- Perform exploratory data analysis (EDA)
- Understand relationships between features and solar energy production
- Clean and prepare the dataset
- Perform feature engineering
- Build and compare multiple regression models
- Tune the best-performing model using GridSearchCV
- Evaluate model performance using appropriate regression metrics
- Identify important features influencing solar energy production
